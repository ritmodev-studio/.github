## RitmoDev — software with a steady pulse

A one-person software studio in Casablanca, Morocco. I build Android and iOS apps, web products and the
backends behind them for clients in Morocco and France, from scoping to launch. You talk to the developer
writing the code.

[ritmodev.com](https://ritmodev.com/en/) · [Français](https://ritmodev.com/) · [العربية](https://ritmodev.com/ar/) · [contact@ritmodev.com](mailto:contact@ritmodev.com)

### What I build

- **[Mobile apps](https://ritmodev.com/en/services/mobile-apps/)**: native Android with Kotlin and Jetpack
  Compose, or React Native with Expo when you need both stores. Store release included.
- **[Web apps & SaaS](https://ritmodev.com/en/services/web-apps/)**: Spring Boot, Angular and PostgreSQL,
  with accounts, payments and deployment done.
- **Backends & APIs**: REST APIs documented with OpenAPI, integrations and database design.

### Case studies

- **[SnapShot](https://ritmodev.com/en/projects/snapshot/)**: guests take one selfie and get every event
  photo they appear in. Face matching runs inside PostgreSQL with pgvector, fed by a stateless FastAPI
  service.
- **[GoalKick](https://ritmodev.com/en/projects/goalkick/)**: booking and management platform for football
  centres in Casablanca. A PostgreSQL exclusion constraint makes double-booking impossible.
